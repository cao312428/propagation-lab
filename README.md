# 传播实验室

**数字内容关键信息传播压力测试工具**

面向海报、校园宣传图和数字内容创作者，检测你主动标记的“必须传达”的重要信息，在传播处理过程中是否发生裁剪、遮挡或功能失效。

> 本工具用于压力测试与问题定位，不预测任何真实平台的传播效果。

---

## 1. 项目简介

《传播实验室》是一款面向海报、校园宣传图和数字内容创作者的关键信息传播压力测试工具。

用户可以在原始作品上主动标记“必须传达”的重要信息区域，例如：

- 标题
- 日期
- 地点
- 二维码
- 其他重要信息

系统随后通过裁剪、界面遮挡、图像缩小、JPEG 压缩等传播条件模拟，分析这些信息在传播处理后发生了什么变化。

核心流程：

```
上传作品 → 标记重要信息 → 模拟传播环境 → 检测变化 → 定位问题 → 修改作品 → 再测试 → 对比修改前后
```

## 2. 核心理念

**信息仍位于画面中，不代表信息仍然有效。**

本工具区分三个概念：

### 几何可见性

- 判断标记区域经过裁剪和遮挡后，还有多少面积保留在最终画面中。

### 二维码真实可解码性

- 使用实际图像像素进行二维码解码。
- 不能因为二维码区域几何上仍然存在，就推断二维码一定能够被扫描。

### OCR 文本识别一致性

- 对比原图与传播处理后图像中的 OCR 识别结果。
- 使用“OCR 文本相似度”等表述。
- 不把 OCR 结果称为人类可读性或阅读体验评分。

## 3. 当前功能

**作品与标注**

- PNG / JPG 图片上传
- 获取原图尺寸
- 基于原图坐标系的矩形标注
- 多个重要信息区域标记
- 标题 / 日期 / 地点 / 二维码 / 其他标签
- 标注删除与重新分类

**裁剪与遮挡模拟**

- 1:1 居中裁剪模拟
- 9:16 居中裁剪模拟
- 裁剪保留率计算
- 通用界面遮挡压力测试
- 最终几何可见率计算

**问题诊断**

- 裁剪与遮挡问题来源诊断
- 受损方向判断
- 基于几何关系的调整建议

**二维码与 OCR 检测**

- jsQR 二维码真实解码
- 原图 / 当前场景 / 画质退化后的二维码识别对比
- Tesseract.js OCR 文字识别
- 原图 / 当前场景 / 画质退化后的 OCR 对比
- OCR 文本相似度

**画质退化压力测试**

- 图像缩放压力测试
- JPEG 压缩压力测试

**版本对比与报告**

- 修改前版本保存
- 修改前后版本对比
- 传播风险报告
- PNG 风险报告导出

## 4. 典型使用流程

1. 上传作品
2. 标记必须传达的重要信息
3. 选择裁剪比例
4. 开启或关闭界面遮挡模拟
5. 查看几何可见性诊断
6. 对二维码进行真实解码测试
7. 运行 OCR 测试
8. 调整缩放和 JPEG 参数进行画质退化压力测试
9. 根据诊断修改设计
10. 保存修改前版本并进行前后对比
11. 导出传播风险报告

- [Vite](https://vite.dev/) — 构建工具与开发服务器

## 6. 技术设计原则

### 原图坐标系

所有标注矩形永久保存为原始图像坐标。

页面显示缩放、窗口尺寸变化、Konva 画布变化、裁剪比例变化都不能修改原始标注坐标。

这样可以保证不同传播场景之间的检测结果基于同一套原始空间数据。

### 检测逻辑与 UI 分离

核心几何、坐标转换、裁剪、遮挡、二维码、OCR、版本比较等逻辑主要放在 `src/utils`，React 页面与组件主要负责交互和结果展示。

## 7. 几何检测规则

当前项目采用以下初始产品规则：

| 最终几何可见率 | 分类 |
| --- | --- |
| ≥ 85% | 完整 |
| 50% ～ 85% | 部分可见 |
| < 50% | 严重缺失 |

> 这些阈值是本项目当前用于压力测试和结果分类的产品规则，不是行业标准，也不是来自某个平台的官方规范。

几何可见率只描述标记区域在空间上剩余的面积比例。它不能直接代表：

- 人类实际阅读效果
- 注意力
- 美学质量
- 信息传播成功率

## 8. 图像画质退化测试

当前支持以下压力测试参数：

**缩放比例**：100%、75%、50%、25%

**JPEG 质量**：90%、70%、50%、35%

> 这些参数用于建立可重复的传播压力测试场景，不代表微信、微博、小红书、抖音等任何真实平台的官方压缩算法或参数。

## 9. 通用界面遮挡说明

项目提供简化的“通用界面遮挡”模型，用于测试重要信息区域是否容易落入顶部、底部或侧边界面覆盖区域。

> 这些遮挡参数属于本项目的压力测试参数，不对应任何具体平台当前版本的官方 UI 尺寸。

## 10. 二维码检测说明

二维码结果来自 jsQR 对实际图像像素的真实解码。

系统会区分：

- 原图是否可以识别
- 当前传播场景是否可以识别
- 画质退化后是否可以识别

如果原图本身就无法识别，系统不会把后续失败错误归因于裁剪、遮挡或画质退化。

## 11. OCR 检测说明

OCR 使用 Tesseract.js。系统主要比较传播处理前后的 OCR 结果变化。

当前使用的指标和状态包括：

- 识别文本保持一致
- 识别文本发生变化
- 传播处理后未能识别文字
- 原图未能识别，无法判断传播影响
- OCR 文本相似度

> OCR 文本相似度不等于人类可读性评分。

## 12. 修改前后版本对比

用户可以将当前结果保存为“修改前版本”，然后重新上传或重新标注修改后的作品进行测试。

系统可比较：

- 最终几何可见率
- 裁剪保留率
- 完整 / 部分可见 / 严重缺失分类
- 二维码识别状态

> 当前版本快照只保存在浏览器运行内存中，刷新页面后不会永久保存。本项目没有数据库，也没有云端版本管理。

## 13. 传播风险报告

报告目前可以汇总：

- 原始图片信息
- 当前测试场景
- 标注数量
- 完整 / 部分可见 / 严重缺失数量
- 几何检测结果
- 问题来源
- 受损方向
- 调整建议
- 二维码结果
- OCR 结果
- 画质退化结果
- 能力边界说明

当前支持以 PNG 图片形式导出风险报告。
